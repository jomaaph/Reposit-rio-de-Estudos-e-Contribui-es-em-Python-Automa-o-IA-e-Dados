## 🤝 Como contribuir

1. Escolha um projeto da lista  
2. Faça o fork no GitHub  
3. Clone para seu PC e estude o código  
4. Faça melhorias, crie novos scripts, corrija bugs  
5. Dê push e crie um **pull request**  
6. Compartilhe aqui para outros estudarem com você!
